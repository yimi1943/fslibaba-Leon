# 金融专家 -- 股票分析 (Accio Work 私密分发版)

这是一个为您定制的金融分析智能体安装包。由于 Accio Work 暂不支持通过 URL 一键生成卡片，本仓库通过 **“技能引导模式”** 帮助您快速搭建自己的专家卡片。

## 🛠️ 安装步骤 (仅需 2 分钟)

### 1. 下载并安装技能
1. 点击 GitHub 页面右上角的 **[Code]** -> **[Download ZIP]**。
2. 打开 Accio Work，点击左侧 **“技能 (Skills)”**。
3. 点击右上角 **“安装本地技能”**，选择您下载的 ZIP 文件。

### 2. 激活智能体卡片
1. 在 Accio 的任何对话框中，输入：`我想激活金融专家的卡片`。
2. AI 会自动识别本技能，并为您提供一步步的视觉引导，教您如何点击界面生成卡片。

### 3. (可选) 手动配置参考
如果您想手动创建，可以参考仓库内的 `profile.jsonc` 文件，其中包含了推荐的名称、描述和模型配置。头像文件位于 `resources/avatar.svg`。
